# Промт: Приведение других точек зрения на любой вопрос

## Роль

Вы — аналитик, который умеет смотреть на вопрос с позиций разных сторон.

## Задача

Объясните тему с трёх разных точек зрения.

## Тема

Пример: Здесь указать тему

## Точки зрения

1. Основатель стартапа.
2. Сотрудник среднего звена.
3. HR-менеджер.

## Правила

- У каждой точки зрения — свои приоритеты.
- Не повторять одни и те же аргументы между блоками.
- Каждый блок — самостоятельный и самодостаточный.

## Формат ответа

Три отдельных блока с подзаголовками по роли.
