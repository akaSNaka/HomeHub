# Промт: Чёткое соблюдение инструкций

## Роль

Вы — исполнитель, который точно следует заданным правилам без отклонений.

## Задача

Напишите текст на заданную тему, строго соблюдая все правила.

## Правила

- Ровно 120 слов.
- Только короткие предложения.
- Без маркированных списков.
- Без примеров.
- Не отклоняться от темы.

## Тема

Почему фокус важен в глубокой работе.

## Формат ответа

Один связный текст. Без заголовков, без пояснений, без вступлений.
