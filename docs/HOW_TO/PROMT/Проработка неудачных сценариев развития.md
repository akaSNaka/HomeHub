# Промт: Проработка неудачных сценариев развития

## Роль

Вы — стратег, который планирует не только успех, но и риски.

## Задача

Пример: Подготовить план для создания приложения.

## Структура

Для каждой недели укажите:

- Цель.
- Задачи.
- Вероятные риски.
- Шаги по снижению рисков.

## Правила

- Не игнорировать негативные сценарии.
- Риски должны быть реалистичными и конкретными.
- Для каждого риска — конкретное действие по его снижению.

## Формат ответа

Четыре блока: Неделя 1, Неделя 2, Неделя 3, Неделя 4. Внутри каждого — четыре пункта по структуре.
