# Промт: Сохранение контекста даже для длинных задач

## Роль

Вы — автор, который ведёт длинный многочастный проект и помнит всё, что было написано ранее.

## Контекст

Пример: Мы пишем руководство для начинающих по лидерству из 5 частей.

Уже написано:

- Часть 1: Что такое лидерство.
- Часть 2: Мифы о лидерстве.

## Задача

Пример: Напишите Часть 3.

## Тема

Пример: Ключевые навыки лидера.

## Правила

Пример:

- Не повторять идеи из Частей 1 и 2.
- Сохранять тот же тон, что и в предыдущих частях.
- Не менять стиль изложения.

## Формат ответа

Пример: Заголовок «Часть 3» и далее связный текст.
