# Git Основные операции

## Проверка состояния проекта

Основная команда:

```powershell
git status
```

Команда показывает:

- новые файлы;
- изменённые файлы;
- подготовленные изменения;
- синхронизацию с GitHub.

Пример чистого состояния:

```text
On branch main
Your branch is up to date with 'origin/main'.

nothing to commit, working tree clean
```

## Просмотр изменений

Команда:

```powershell
git diff файл
```

Показывает изменения в файле, которые ещё не были сохранены в commit (сохранение версии).

Для новых файлов сначала нужно добавить их в область подготовки:

```powershell
git add файл
```

После этого изменения можно посмотреть:

```powershell
git diff --cached
```

## Добавление изменений

Добавить один файл:

```powershell
git add имя_файла
```

Добавить все изменения в папке:

```powershell
git add .
```

## Создание commit

Commit (сохранение версии проекта):

```powershell
git commit -m "описание изменения"
```

Пример:

```powershell
git commit -m "docs: update git guide"
```

## Отправка изменений на GitHub

Команда:

```powershell
git push
```

После успешной отправки проверить состояние:

```powershell
git status
```

## Если терминал не принимает команды

Признак:

Команды не выполняются.

Возможные причины:

- PowerShell (терминал) ожидает продолжение ввода;
- открыт режим просмотра Git;
- выполняется предыдущая команда.

Решения:

1. Нажать:

```text
Ctrl + C
```

Команда отменяет текущий ввод.

1. Если открыт просмотр Git:

```text
Q
```

Важно:

Раскладка клавиатуры должна быть английская.

1. Проверить наличие приглашения PowerShell:

```text
PS C:\Projects\homehub>
```

## Проверка перед commit

Перед сохранением изменений выполнить:

```powershell
git diff
```

Проверить, что изменения ожидаемые.

Затем:

```powershell
git status
```

Убедиться, что подготовлены только нужные файлы.

## Типовой порядок работы

```text
1. Изменить файл.

2. Проверить изменения:
git diff

3. Добавить изменения:
git add файл

4. Проверить подготовленные изменения:
git diff --cached

5. Создать commit:
git commit -m "описание"

6. Отправить на GitHub:
git push

7. Проверить результат:
git status
```
