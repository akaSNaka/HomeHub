# Markdown правила проекта

## Структура документов

Каждый документ должен иметь:

- один главный заголовок `#`;
- разделы второго уровня `##`;
- пустые строки между блоками.

## Кодировка файлов

Все файлы проекта должны использовать UTF-8.

Проверка:

VS Code → кодировка файла → UTF-8.

Не использовать:

- ANSI
- Windows-1251

## Конец файла

Каждый файл должен заканчиваться одной пустой строкой.

Проверка:

Markdownlint правило MD047.
