Вайбкодинг (vibe coding) — это подход, где ты создаёшь приложения через быстрые итерации с помощью AI, описывая словами, что хочешь получить, а не пишешь весь код вручную. Но чтобы делать это качественно, нужно понимать базовые принципы разработки: архитектуру, данные, ошибки, безопасность и работу с инструментами.

Ниже — практический план входа с нуля до самостоятельной разработки проектов.

 2. Ещё один очень важный вывод

Я изменяю нашу первоначальную архитектуру.

Раньше я предлагал:

Expo
+
Supabase

как основу.

Теперь я бы не фиксировал Supabase навсегда.

Почему?

Мы уже понимаем, что потенциально строим серьёзную self-hosted (самостоятельно размещаемую) систему.

Поэтому лучше:

Application
      │
      ▼
Repository / Service layer
      │
      ▼
Database

а не:

Application
      │
      └──────> Supabase everywhere

То есть Supabase может быть нашей первой реализацией, но приложение не должно зависеть от Supabase на каждом уровне.

Это называется abstraction layer (слой абстракции).

 1. И тогда появляется очень мощная возможность

Сегодня:

HomeHub
   ↓
Supabase

Позже:

HomeHub
   ↓
Supabase

или:

HomeHub
   ↓
Self-hosted PostgreSQL

или:

HomeHub
   ↓
Local server

То есть мы сможем постепенно прийти к:

«Все данные находятся у пользователя».

Это соответствует философии Yuvomi и Grocy, которые делают сильный акцент на self-hosting (самостоятельном размещении) и контроле данных.
